# Mobile Research — рынок приложений для изучения английского

Интерактивный исследовательский отчёт по рынку приложений для изучения английского языка: объём рынка, причины оттока, механики удержания, реальная эффективность обучения, незакрытые ниши, разбор платформ и эскиз технической архитектуры.

## Разделы

- **Негатив** — топ жалоб пользователей по категориям приложений.
- **Механики** — как приложения удерживают пользователей (streak, лиги, XP, push, freemium, SRS).
- **Обучение** — что реально работает, а что нет; эффективность по навыкам.
- **Возможности** — системные пробелы рынка и идеи для нового продукта.
- **Платформы** — как устроены HelloTalk, Tandem, Busuu, Memrise, Anki, Duolingo, LingQ, Skyeng и др.; видео-окна (Memrise, EWA — официальные каналы) и виджет Youglish.
- **Архитектура** — диаграммы технического скелета приложения: слои сервисов, граф навыков CEFR и ER-модель хранилища контента.

## Технологии

- Чистые HTML / CSS / JavaScript, без сборщика.
- [Mermaid](https://mermaid.js.org/) — диаграммы архитектуры.
- YouTube IFrame Player API и виджет [Youglish](https://youglish.com/) — видео-окна.
- [Tabler Icons](https://tabler.io/icons) и шрифт Inter.
- Светлая/тёмная тема с сохранением выбора.

## Запуск локально

Часть видео (YouTube) требует протокол `http://`, поэтому запускайте через локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Структура

```
index.html    разметка и контент
styles.css    стили и дизайн-система (темы, анимации)
script.js     темы, вкладки, видео-окна, рендер диаграмм
```
